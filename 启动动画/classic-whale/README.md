# 经典鲸鱼启动动画

DSH 外壳冷启动时那段画面：**鲸鱼 logo 呼吸漂浮 → 标题 → 阶段文字 → 渐变流动进度条**，3.2 秒走完。

## 里面有什么

| 文件 | 说明 |
|---|---|
| `src/classic.html` | 单文件复刻，零依赖，双击就能看 |
| `src/whale.png` | 鲸鱼 logo（6 KB） |
| `preview.mp4` | 640×360 / 15fps / 4 秒 的预览 |
| `poster.jpg` | 封面帧（进度 54% 那一刻） |

## 怎么用

1. **只看效果**：双击 `src/classic.html`
2. **接进工作台**：把这段动画放进启动遮罩，进度条宽度改成由真实加载进度驱动
3. **要生成同款预览**：用逐帧截图 + ffmpeg 合成（见仓库 `tools/` 同款做法）

这个文件还暴露了一个 `window.renderAt(秒)`：给定时间点，把整段动画渲染成那一刻的静止画面。
录帧、做封面、生成 GIF 都靠它，不用真的播放一遍再截屏。

## 改哪里

| 想改 | 改哪 |
|---|---|
| 标题 / 阶段文字 | `classic.html` 里的 `stages` 数组 |
| 进度条颜色 | `.in` 的 `linear-gradient` 两个色值 |
| 整体时长 | `renderAt` 里 `(t - 0.3) / 3.0` 的 3.0 秒 |
| logo 大小 / 漂浮幅度 | `.logo` 的宽高与 `@keyframes pulse` |

## 坑

- **进度条是假进度**：`renderAt` 里按时间算的。真接进外壳时，宽度必须由宿主的真实状态驱动，
  否则会出现「动画走完了但引擎还在加载」的尴尬。
- **截图前必须冻结 CSS 动画**：用负的 `animation-delay` + `animation-play-state: paused`，
  否则每次截到的是不同帧，合成出来的视频会抖。
- 深色背景下这条渐变进度条很亮，浅色主题要自己换一版配色（不然会糊成一片）。
